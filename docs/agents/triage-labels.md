# Triage labels

Canonical roles from the triage skill → strings used in Linear.

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | *(status: Backlog)*  | Maintainer needs to evaluate this issue  |
| `needs-info`               | *(status: Backlog)*  | Waiting on reporter for more information |
| `ready-for-agent`          | *(status: Todo)*     | Fully specified, ready for an AFK agent  |
| `ready-for-human`          | *(status: Todo)*      | Requires human implementation            |
| `wontfix`                  | *(status: Canceled)* | Will not be actioned                     |
| `bug`                      | Bug                  | Something is broken                      |
| `enhancement`              | Feature / Improvement | New feature or improvement              |

See `docs/agents/issue-tracker.md` for status mapping.
